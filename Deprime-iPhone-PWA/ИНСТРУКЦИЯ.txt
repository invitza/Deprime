DEPRIME — PWA-версия для установки на iPhone

ВАЖНО: это подготовленный набор файлов, приложение ещё НЕ опубликовано в интернете. Для установки на iPhone сайт должен быть размещён на HTTPS-хостинге.

1. Загрузите содержимое этой папки на статический HTTPS-хостинг (например, GitHub Pages). Главный файл — index.html; рядом должны лежать manifest.json, service-worker.js и папка icons.
2. Откройте опубликованный HTTPS-адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Ограничения текущей версии:
- Это PWA, не нативная iOS-сборка .ipa и не публикация в App Store.
- Локальные музыкальные файлы/Blob и данные IndexedDB не переносятся автоматически с Windows на iPhone.
- Офлайн-кэш оболочки не гарантирует офлайн-воспроизведение внешней музыки.
- Для синхронизации плейлистов между устройствами нужна отдельно проверенная облачная интеграция.
